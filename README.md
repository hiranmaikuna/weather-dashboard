# 🌤️ Weather Dashboard

A real-time Weather Dashboard built using HTML, CSS, and asynchronous JavaScript.

## Features

- Search weather by city name
- Real-time temperature
- Humidity information
- Wind speed
- Fetch API
- Async/Await
- Error handling
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- REST API
- Fetch API
- Async/Await

## API

This project uses the Open-Meteo API to retrieve weather information.

## How to Use

1. Enter a city name.
2. Click the Search button.
3. The current weather information will be displayed.
